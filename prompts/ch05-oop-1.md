# Prompts for *Chapter 5 Building Your Own Types with Object-Oriented Programming*

```
Please explain encapsulation, composition, aggregation, inheritance, abstraction, and polymorphism by designing one coherent C# model for a television production company.
```

```
Please explain how a project’s target framework and C# language version interact. Show examples of modern C# syntax that can target .NET Standard 2.0 and features that also require newer runtime or library support.
```

```
Teach me how to design a flags enum correctly. Cover `None = 0`, powers-of-two values, composite values, bitwise operators, `HasFlag`, validation, and choosing an underlying integer type.
```

```
Please explain the binary versioning problem with `public const` fields in class libraries. Compare `const`, `static readonly`, and instance `readonly` fields with examples.
```

```
Please explain parameter passing by value, `in`, `ref`, and `out` for both value types and reference types. Include diagrams showing what is copied and what can be changed.
```

```
Compare `params` arrays with `params` collections. Explain how calls are translated, when allocations occur, and when a normal collection parameter would be clearer.
```

```
Please explain tuple field names, inferred tuple names, tuple aliases, deconstruction, discards, and tuple equality with short C# examples.
```

```
Please explain how `Deconstruct` methods work, how overload resolution chooses among them, and why two `Deconstruct` methods with the same number of parameters can be problematic.
```

```
Please explain modern partial types and partial members. Distinguish optional partial methods from partial methods whose implementations are required and show how source generators use them.
```

```
Compare public fields, private fields, automatically implemented properties, field-backed properties, computed properties, init-only properties, and required properties. Show when each should be used.
```

```
Review several proposed C# indexers and identify which ones provide intuitive collection-like behavior and which would surprise callers.
```

```
Please explain why C# records are not automatically deeply immutable. Demonstrate mutable record properties, shallow copying with `with`, and techniques for designing genuinely immutable object graphs.
```

```
Compare returning several values using `out` parameters, tuples, records, and small result classes. Give guidance for private methods and public APIs.
```

```
Compare constructors, object initializers, required members, init-only properties, primary constructors, and positional records. Show situations where each produces the clearest API.
```

```
Compare C# union types with inheritance hierarchies, interfaces, enums with optional properties, discriminated unions in F#, Rust enums, Swift enums, and TypeScript unions.
```
